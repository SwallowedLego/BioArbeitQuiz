# BioArbeitQuiz

Eine einfache, statische Quiz-Webseite rund um Bakterien, Viren und das Immunsystem.

## Nutzung

1. Öffne die Datei `index.html` im Browser (Doppelklick oder per lokalem Webserver).
2. Beantworte die Fragen und klicke auf **„Antworten prüfen“**, um dein Ergebnis zu sehen.
3. Mit **„Zurücksetzen“** kannst du das Quiz erneut starten.
